# Change records

One file per branch (`feat/hexa-sort-cascade` → `feat__hexa-sort-cascade.md`), copied from `TEMPLATE.md`.

It is three things at once:
1. **Design proposal** that a human approves before code changes (`Status: PROPOSED` → `Status: APPROVED`, set by a person).
2. **Explanation** of how the change respects Clean Architecture, SOLID and the design patterns, used as the PR description.
3. **Evidence** for `AI_USAGE.md`: which parts were AI-assisted and what the team changed.

Records are committed with the code they explain and are never rewritten after merge.
